KENAPA 20Hz BUTUH FFT GEDE

20Hz = 1 gelombang 50ms.
FFT harus lebih panjang dari itu.

512 = 10ms → 20Hz hilang
2048 = 42ms → 20Hz kasar
16384 = 341ms → 20Hz bener
32768 = 682ms → paling bener, tapi lambat

Jadi kalo mas mau liat sub, jangan pake CEPAT.
