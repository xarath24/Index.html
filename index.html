VIDA MUSIC

Cari dan putar video musik berdurasi penuh langsung di dalam aplikasi.
Masukkan API key YouTube Data API untuk mengaktifkan pencarian.
▶
Pilih lagu dari hasil pencarian
Belum ada video diputar
Aplikasi ini memakai YouTube Data API v3 untuk mencari video dan YouTube IFrame Player resmi untuk memutarnya. API key diperlukan. Pemutaran penuh bergantung pada izin video, wilayah, dan aturan YouTube. VIDA tidak dapat menghapus iklan YouTube atau memaksa pemutaran latar belakang. API resmi YouTube Music untuk streaming lagu penuh tidak tersedia secara publik.
