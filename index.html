ROUTING INPUT

1. Input 1 (Left): ambil sinyal reference dari output DSP/mixer melalui line-level yang sesuai.

2. Input 2 (Right): sambungkan measurement microphone dengan phantom power hanya jika mikrofon membutuhkannya.

3. Arahkan mikrofon ke speaker yang diuji dan jalankan pink noise / test signal.

4. Tekan Start Live. Nilai akan bergerak otomatis mengikuti pengukuran.

Jarak ekuivalen = delay × kecepatan suara. Ini bukan otomatis jarak fisik speaker karena latency DSP/interface ikut terukur. Hasil terbaik memerlukan gain stabil, routing benar, dan sinyal reference yang bersih.

PANDUAN

1. RTA: buka halaman melalui HTTPS, izinkan mikrofon, lalu Start Mic RTA.

2. Auto FIR: import CSV respons frekuensi speaker (frequency Hz, magnitude dB).

3. Find Delay LIVE: gunakan audio interface stereo 2-input; Input 1 reference, Input 2 mikrofon ukur, lalu Start Live.

4. Export WAV/CSV dan uji pada DSP dengan level rendah serta limiter aktif.

Jangan mengoreksi null akustik yang dalam dengan boost besar. Hasil bukan preset universal semua speaker/ruangan.
