SETUP PENGUKURAN

1. Hubungkan output reference/interface ke channel 1 (Left).

2. Hubungkan microphone measurement ke channel 2 (Right).

3. Rekam sinyal test yang sama ke kedua channel secara bersamaan.

4. Export sebagai WAV stereo tanpa pemrosesan otomatis.

5. Import WAV dan tekan FIND DELAY.

Jarak ekuivalen = delay × kecepatan suara. Nilai ini bukan otomatis jarak fisik speaker jika ada latency DSP/interface.

PANDUAN

1. RTA: buka halaman melalui HTTPS, izinkan mikrofon, lalu Start Mic RTA.

2. Auto FIR: import CSV respons frekuensi speaker (frequency Hz, magnitude dB).

3. Atur sample rate, taps, boost/cut, smoothing dan target. Tekan Generate Auto FIR.

4. Export WAV/CSV dan uji pada DSP dengan level rendah serta limiter aktif.

Jangan mengoreksi null akustik yang dalam dengan boost besar. Hasil bukan preset universal semua speaker/ruangan.
